自托管漫画 / 电子书阅读器

支持 AI 翻译的 漫画书库

以漫画为主、同时支持 PDF、EPUB 等电子书的自托管书库。以 LANraragi 为起点，用 Rust + React 大幅改造与强化，现有的 LANraragi 书库可以直接使用。内置漫画页面翻译、相似作品推荐和 AI 插件生成。

第1話

AI 功能

翻译、编写插件、整理单行本等原本需要手动完成的工作，可以交给 AI 处理。所有 AI 功能都是可选的，不配置 API 密钥也不影响其它功能。

页面内翻译

漫画页面翻译

用针对漫画的 OCR 识别竖排和横排文字，按字形擦除原文、保留画面，再把译文按原文方向排回对话框。术语表让人名、招式名在整卷中保持一致，字体缓存让同一卷的译文字体统一。

  1. 文字检测
  2. 漫画 OCR
  3. 字形擦除
  4. LLM 翻译
  5. 回填排版
  • 支持云端或本地翻译后端
  • 显示翻译费用，可设置上限
  • 翻译结果会保存，再次打开无需重新翻译

推荐

读完一本，推荐下一本

先用本地 ONNX 嵌入模型从整个书库中筛选候选，再由 LLM 排序。单行本以最后一卷为准，不会把第 1 卷推荐回来。

整理

把零散文件整理成单行本

用本地模型找出属于同一系列的散档案，建议建成单行本（这一步不需要 API 密钥）；再根据文件名里的卷号和话数，由 AI 建议系列名、章节标题与阅读顺序。整个子目录也能直接建成单行本。

标签自动补全

元数据插件找不到标签时，由 LLM 根据标题和已有信息补全。

用自然语言写订阅条件

描述想追什么样的作品，AI 会把它转换成订阅的筛选规则；规则保存前会先经过校验。

AI 功能由 DeepSeek 驱动

插件生成、推荐精排、标签补全、单行本命名与排序、拆包方案和订阅条件生成都调用 DeepSeek，需要一个 DeepSeek 官方 API 密钥，在首次运行向导或设置页填写即可。页面内翻译可以另选 OpenAI 兼容接口、Anthropic 或本地模型。不填密钥，书库和阅读器照常使用。

第2話

阅读与管理

  • ⇄

    单行本连续阅读

    同一套单行本的各卷连成连续的页面，翻页可直接跨卷，阅读进度与书签按卷分别记录。

  • ≡

    章节目录

    封面、彩页、后记一键设置，数字键快速标记章节；优先显示 AI 生成的章节名。

  • ✦

    页码级书签与图章

    书签精确到页；图章可以框选标注画面的一部分，放置图章时自动添加书签。

  • ▦

    概览无限滚动

    缩略图按需加载，几百页的合集也能快速打开，滚动条不会跳动。

  • ◫

    图片自动转换

    浏览器显示不了的格式（例如部分浏览器上的 AVIF、JPEG XL 和动画图）会先转换再显示；也可以把大图缩小并转成 WebP 或 JPEG XL 后再发送，节省流量。

  • ◐

    访客模式

    访客只能浏览你指定的分类，看不到其它内容。

第3話

下载与整理

  • ↓

    服务端下载器

    下载由服务端完成，显示实际字节进度和剩余时间；可按域名设置并发上限和限速，同一地址不会重复下载。Pixiv 这类按页下载的作品会打包成一个档案。

  • ↻

    订阅追更

    按来源站点加作者、标签、评分下限、发布时间等条件建立订阅，定时检查新作并自动下载。预览会列出每个候选的处理结果，可以一键拉黑或撤销；之后评分或标签有变化，会重新判断。

  • ⇅

    新旧版本识别

    根据站点提供的版本链判断新下载比库里的更新还是更旧：更新的可按设置替换旧档案，新档案入库后才删除旧的；更旧的可以拒绝，或在下载前先询问。

  • ✂

    拆包

    自动找出多卷合集、多层目录和压缩包里套压缩包的档案，给出拆分方案，确认后在后台执行。拆出的文件由 AI 命名，可同时迁移单行本成员、删除原文件。

  • ⧉

    可视化补页

    上传的档案和库里已有档案内容高度重合时，会逐页比对并并排显示差异；把多出的页面拖到对应位置，就会生成页面补丁，不必替换整个档案。

  • 文

    乱码名称修复

    找出档案、分类、单行本和标签名称里的乱码，先列出修复结果供确认，确认后再应用，并同步更新搜索索引。

第4話

兼容 LANraragi 书库

沿用 LANraragi 的书库目录结构与 HTTP API，第三方阅读器照常连接。标签、分类等元数据从 LANraragi 的备份导入，两边的数据库互不影响。

从 LANraragi 迁移

  1. 在 LANraragi 导出备份

    设置 →「Database Backup/Restore」→「Backup Database」，下载 JSON 文件。LANraragi 可以继续运行。

  2. 启动 LANrurugi

    书库挂载和 LANraragi 相同的漫画目录；缩略图和数据库也要挂载，但必须用新的目录，不要和 LANraragi 的相同。

    用转换器从 LANraragi 的部署生成 compose →

  3. 登录

    kamimamita

    打开 http://<server>:3000，用默认密码 kamimamita（与 LANraragi 相同）登录。首次运行向导会提示你改成自己的密码。

  4. 导入备份

    在向导的「从 LANraragi 备份导入」一步上传 JSON；之后也能在 设置 →「数据库备份/恢复」里导入。标签、分类、合集和 stamps 会恢复，阅读进度不在备份里。档案按文件名对应，请等书库扫描完成再导入。

最終話

用 Docker Compose 部署

  1. 复制 compose 文本

    点右边的「复制」，保存为 compose.yaml，再按注释把目录改成你自己的。

  2. 启动

    docker compose up -d

    NAS 用户：在群晖 Container Manager、Portainer 等面板里新建 compose 项目，粘贴同一段文本即可。

  3. 打开浏览器

    http://<server>:3000

    首次打开时，设置向导会引导你修改默认密码、填写 AI 功能所需的 API 密钥，并导入 LANraragi 备份。

要放在 Nginx、Caddy、Traefik 等反向代理之后？ 查看反向代理配置示例

LANrurugi 的缩略图和数据库目录必须和 LANraragi 的分开，不要指向同一个路径；两边可以同时运行。标签、分类等元数据通过 LANraragi 的备份 JSON 导入，首次运行向导里就有这一步。

同一个镜像也发布在 Docker Hub： jade913/lanrurugi

已经在用 LANraragi？把部署命令或 compose 转换成 LANrurugi 的

粘贴 LANraragi 的 docker run 命令或 compose.yaml，书库目录会填进上面的 compose 文本，缩略图和数据库用 LANrurugi 自己的目录，端口换成原端口的下一个。转换只在你的浏览器里进行，不会上传任何内容。

    不用 Docker

    Linux（x86_64 / ARM64）、Apple Silicon Mac 和 FreeBSD 有原生安装包：用系统的包管理器装好 Redis、Deno 等依赖，解压后直接运行，也可以注册为系统服务。Windows 请使用 Docker Desktop。
