Download a whole tankoubon as one zip
Section titled “Download a whole tankoubon as one zip”


GEThttp://localhost:3000/api/tankoubons/{id}/download


Every member archive in tankoubon order, each as its original file, stored rather than
re-compressed. Entries are named NN - <title>.<ext>, so they list in reading order. An archive
with a patch sidecar is delivered merged, as the single-archive download does.


The body is streamed as it is produced: there is no Content-Length, and nothing is prepared
on the server first. A member whose file cannot be read is left out, and a final MISSING.txt
names it.


Administrators only; read-only tokens and guest visitors are refused.


Path parameters
idstringrequired
The tankoubon id (TANK_…).
Responses
200The zip stream.
This response carries no example body.
404No tankoubon with this id.
This response carries no example body.

Update Tankoubon reading progression
Section titled “Update Tankoubon reading progression”


PUThttp://localhost:3000/api/tankoubons/{id}/progress/{page}


Tell the server which page of this Tankoubon you’re currently reading, so that it updates its internal reading progression accordingly.
The page number is global across all Archives in the tank  (If a tank has two Archives with 20 and 25 pages, page 26 will be page 6 in Archive #2).
⚠ If the server is configured to use clientside progress tracking, this API call will return an error!
Make sure to check using /api/info whether the server tracks reading progression or not before calling this endpoint.


Path parameters
idstring · min: 15 · max: 15 · patternrequired
ID of the Tankoubon to update.
pageinteger · min: 1required
Global 1-indexed page number to update the reading progress to. Must be a positive integer.
Responses
200Success response
{
  "id": "TANK_1589141306",
  "lastreadtime": 123943543,
  "operation": "update_tank_progress",
  "page": 5,
  "success": 1
}

{
  "error": "Server-side Progress Tracking is disabled on this instance.",

  "success": 0

  "error": "This operation requires authentication.",

Get Tankoubon thumbnail
Section titled “Get Tankoubon thumbnail”


GEThttp://localhost:3000/api/tankoubons/{id}/thumbnail


Get the cover thumbnail for a given Tankoubon.  By default, the thumbnail is sourced from the first page of the first archive.  This endpoint will return a placeholder image if it doesn’t already exist.  If you want to queue generation of the thumbnail in the background,  you can use the no_fallback query parameter.


Query parameters
no_fallbackstring · enum: true | falseoptional
Disables the placeholder image, queues the thumbnail for extraction and returns a JSON with code 202. This parameter does nothing if the image already exists. (You will get the image with code 200 no matter what)
Responses
200If the thumbnail was already extracted, you get it directly.
This response carries no example body.
202The thumbnail is queued for extraction. Use `/api/minion/:jobid` to track when your thumbnail is ready.
{

  "operation": "",
  "success": 1
}
