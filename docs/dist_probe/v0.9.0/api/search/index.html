搜索 API

对档案索引执行搜索。

搜索档案

Section titled “搜索档案”
GEThttp://localhost:3000/api/search

搜索档案。这个 JSON 里的 ID 可以用在其他端点上。

权限差异

  • 访客（开启访客访问时的未认证访问者）只能看到所属分类被标记为「访客可见」的档案；其他身份能看到整个书库。

查询参数

categorystring · min: 14 · max: 14 · pattern可选
限定本次搜索范围的分类 ID。
filterstring可选
搜索查询串。可以在这当中使用下列特殊字符： 双引号 ("...") 精确字符串搜索。让一个搜索词可以包含空格；一对双引号内的所有内容会被当成单个词条处理。通配符仍然按通配符解释。 问号 (?)、下划线 (_) 通配符，匹配任意单个字符。 星号 (*)、百分号 (%) 通配符，匹配任意长度的字符序列（也可以一个都不匹配）。 减号 (-) 排除。放在某个词前面，搜索结果就不会包含该词。 美元符号 ($) 加在标签末尾，对该标签做精确搜索，而不是显示所有以该词开头的结果。它只匹配标签，不受搜索参数影响，因此也可以当作排除项，用来在搜索里忽略杂项标签。
startinteger可选
从结果总数中的第几个档案开始枚举。单页显示的档案数取决于服务端的每页条数偏好。 从 0.8.2 起，这里传 "-1" 可以取到完整的、不分页的数据。
sortbystring可选
结果排序所依据的命名空间。可用的排序键有： - *title*：按标题排序 - *lastread*：按上次阅读时间排序（需开启 服务端进度跟踪 ） （默认值是 title。按 lastread 排序时，从未读过的 ID 会被从搜索结果里移除。）
orderstring可选
排序方向，asc 或 desc。
newonlyboolean可选
只搜索未读过的档案。
untaggedonlyboolean可选
只搜索未打标签的档案。
hidecompletedboolean可选
隐藏已读到末尾的档案。
groupby_tanksboolean · default: true可选
启用或关闭 Tankoubon 分组，默认开启。 开启时，搜索结果里会显示 Tankoubon，取代它包含的所有档案 ID。

新增的轻量端点，为书库搜索框的标题自动补全提供数据。与 /search 不同，它只返回前几个匹配项中的 arcid + title——没有标签、进度或体积——因为前端每敲一次键（已做防抖）就会调用它，而一次返回 100 条档案记录的完整 /search 页会有几百 KB 的 JSON，建议列表拿到后立刻就丢掉了。查询语法相同、筛选相同、默认的 title 排序也相同（这正是建议列表想要的），并且访客范围限制也相同：这里同样应用 restrict_to_archive_ids，因此 guest_visitor 绝不可能通过这个端点看到一个 /search 会拒绝返回的越界标题。
