OPDS Catalog

3 endpoints.

Get the OPDS Catalog

Section titled “Get the OPDS Catalog”
GEThttp://localhost:3000/api/opds

Get the Archive Index as an OPDS 1.2 Catalog with PSE 1.1 compatibility.

Query parameters

categorystringoptional
Category ID. If passed, the OPDS catalog will be filtered to only show archives from this category.

Responses

200OPDS catalog XML

This response carries no example body.

Request failed — Usual causes: the instance address is wrong or unreachable; cross-origin access is not enabled on the instance; or this page is HTTPS while the instance is plain HTTP on a LAN address, which the browser blocks as mixed content. “Copy as cURL” above sends the same request from a terminal.
