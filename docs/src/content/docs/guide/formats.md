---
title: 支持的格式
description: 能放进书库的压缩包与电子书格式，以及每种格式怎么显示、目录从哪里来。
---

书库里的每个文件都是一本「档案」，在同一个阅读器里一页一页地读。除了装着图片的压缩包，PDF、EPUB 等
电子书也可以直接放进书库目录或通过上传页加入，不需要先转换。

## 压缩包

| 格式 | 扩展名 |
| --- | --- |
| ZIP | `.zip` `.cbz` |
| RAR（含 RAR5） | `.rar` `.cbr` |
| 7-Zip | `.7z` `.cb7` |
| TAR | `.tar` `.cbt`，以及 gzip / bzip2 / xz / lzma 压缩的 tar（`.gz` `.bz2` `.xz` `.lzma`） |
| LZH | `.lzh` `.lha` |

压缩包里能作为页面的图片：PNG、JPEG（`.jpg` `.jpeg` `.jfif`）、GIF、BMP、WebP、AVIF、JPEG XL、HEIF/HEIC。
浏览器显示不了的格式（例如部分浏览器上的 AVIF、JPEG XL 和动画图）会由服务端转换后再显示；HEIF/HEIC 目前
无法转换，只有原生支持它的浏览器（例如 Safari）能显示。

用 zstd 压缩的文件（`.zst`）目前不支持，不会被收录。

## 电子书

| 格式 | 扩展名 | 页面怎么显示 | 目录从哪里来 |
| --- | --- | --- | --- |
| PDF | `.pdf` | 扫描页直接输出 PDF 里存的原图；文字页、矢量页渲染成图片 | PDF 书签 |
| EPUB（固定版式） | `.epub` | 每一页输出书里存的原图 | 书自带的目录（nav / NCX） |
| EPUB（流式文字） | `.epub` | 服务端排版成页，插图随文排入 | 书自带的目录，精确到章节所在的位置 |
| MOBI / AZW / AZW3 | `.mobi` `.azw` `.azw3` `.prc` | 漫画：每页输出原图；文字书：服务端排版 | 书里的目录页或章节标题 |
| DjVu | `.djvu` `.djv` | 渲染成图片 | DjVu 书签 |
| FB2 | `.fb2` | 服务端排版，插图随文排入 | 书的章节结构 |
| 纯文本 | `.txt` | 服务端排版 | 自动识别「第一章」「第十二回」「序章」「Chapter 3」这类章节行 |

几点说明：

- **原图不重新压缩。** 书里存的是图片的页面（扫描版 PDF、固定版式 EPUB、漫画 MOBI/AZW3、FB2 插图），
  阅读器拿到的就是书里那张图本身。
- **文字书由服务端排版。** 正文按书的语言选用简体中文、日文或韩文字体，标题、段落、插图都会排进页面；
  目前只支持横排。
- **目录只在首次入库时导入**，而且只在档案还没有章节目录时才导入，不会覆盖你手动编辑过的目录。书自带的
  目录缺失或只有一两条（比如只有封面、版权页）时，会从正文里的标题和章节行补全。
- **TXT 只收录 8 KB 以上的文件**，避免把书库里的说明文件、备注当成书。编码自动识别（UTF-8、UTF-16、
  GBK/GB18030、Big5、Shift_JIS、EUC-JP、EUC-KR 等）；按固定宽度折行的文本会重新拼回段落。
- **书库里会标出格式。** 电子书在标题旁显示 `PDF`、`EPUB` 之类的小标签；PDF 还可以在阅读页里直接用浏览器
  打开原文件。
- 拆包建议只对压缩包有意义，电子书不提供。
- 文字书和 PDF 文字页渲染出的页面会缓存起来，与阅读器的其它缓存一起受
  「设置 → 档案文件 → 最大阅读缓存大小」限制。

## 不支持的情况

- **带 DRM 或密码保护的书**（例如从商店购买、未去除保护的 Kindle 书，或加了打开密码的 PDF）无法读取。
  这类文件仍会出现在书库里（0 页），打开时阅读器会显示无法读取的原因（受 DRM 或密码保护），服务端日志里也会
  记录。
- **损坏或不完整的文件**同样会提示具体原因，不影响书库里的其它书。
- Kindle 的 KFX 格式，以及使用 HUFF/CDIC 压缩的 MOBI（多见于 Kindle 词典）暂不支持。
