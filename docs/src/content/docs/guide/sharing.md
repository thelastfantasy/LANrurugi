分享让你把一部分藏书交给别人：对方可以在浏览器里阅读、下载，或者直接导入到他自己的
LANrurugi 实例里，标签、简介和单行本结构都会一起过去。只有登录的管理员能创建分享，访客模式下看不到任何分享功能。

## 创建分享

在书库里右键一个或多个档案、单行本（可以混选），或在阅读器的菜单里，选择 **分享…**。

- **新建分享**：填写下面的选项后生成分享码。
- **添加到已有分享**：把选中的条目加进一个还有效的分享，同时可以重新设置它的下载次数和 IP 限制。

生成后你会得到：

- 一个分享码（例如 `K7QM9-XRT2H`）、它的完整文本（`lrrg:K7QM9-XRT2H?r=…`）和对应的二维码；
- 填写了**公开地址**时，还有一个浏览器链接 `…/s/<分享码>`，以及开启嵌入时的嵌入代码。

完整文本里加密附带了本实例当前的连接路线（地址、中继、节点），文本中看不到明文地址。对方用完整文本导入时，
会直接按这些路线连接，不依赖任何公共服务；只发前面的分享码也能导入，但要靠公共查询服务或节点找到本实例。

分享码只在生成时和「显示分享码」时出现。实例本身只保存它的指纹和加密副本，别人无法从数据库里读出分享码。

### 权限

每个分享可以任意组合三种权限：

| 权限 | 对方能做什么 |
|---|---|
| 导入 | 用自己的 LANrurugi 导入这些内容 |
| 阅读 | 在浏览器里翻页阅读，有章节目录时可以按章节跳转 |
| 下载 | 在浏览器里下载档案文件；单行本打包成一个 zip |

只给「导入」时，分享卡片和分享页只显示分享码与二维码，不提供浏览器阅读。

### 限制

- **下载次数**：每次导入、每次浏览器下载各算一次。同一次导入中断后续传、重试都不会重复计数。用完后分享关闭：分享页和嵌入卡片只显示“下载次数已达上限”，不能再浏览、下载或导入；已经在进行的导入不受影响。
- **IP 限制**：只允许列出的地址或网段，或者「只允许前 N 个不同地址」。有 IP 限制的分享要求对方能被直接连到，经中继转发的连接无法核实地址，会被拒绝。
- **有效期**：到期后分享自动失效。
- **短分享码**：8 位短码更好念，但必须设置 7 天以内的有效期。

### 管理和撤销

**设置 → 分享** 列出所有分享。展开一行可以看到条目、每次领取的时间与地址、协助分发的实例，并修改所有选项。

**撤销**立即生效：正在进行的导入会在半分钟内停止，链接和嵌入卡片显示「已撤销」。被分享的条目从书库删除时，分享里会显示为「已不可用」，其余条目不受影响。

## 导入别人的分享

在 **上传** 页点击 **导入分享**，然后任选一种方式：

- 粘贴或输入分享码（大小写、空格、连字符都无所谓；整段 `lrrg:` 文本或分享链接也可以直接粘贴）；
- 粘贴二维码截图，或上传二维码图片；
- 用摄像头扫码。

二维码完全在你的浏览器里识别，图片不会上传到任何地方。

:::note[通过 HTTP 访问时]
浏览器只在 HTTPS（或 `localhost`）页面上允许使用摄像头。用 HTTP 打开实例时，扫码按钮会改为「拍照」，在手机上会直接调起相机拍一张二维码照片，效果相同。
:::

识别后会先显示预览：标题、封面、数量和总大小，以及哪些档案你已经有了（这些不会重复下载）。选择要放入的分类，确认后导入作为一项任务出现在下载队列里，可以暂停、继续和查看每个档案的进度。

- 每一块数据在写入前都会校验，最终文件与对方的原文件逐字节相同。
- 导入中断（任一方重启、断网）后会从已校验的部分继续。
- 单行本按原来的卷序重建，标题、标签、简介和章节目录一并导入；你自己已有的标签会保留并合并，档案已经有章节目录时保留你自己的。书签和图章属于分享方个人，不会导入。

### 协助分发

导入时勾选 **帮助分发此分享**，并且分享方允许协助分发时，你的实例在导入完成后会把已校验的数据提供给其他导入者，减轻分享方的上传压力。其他人拿到的每一块数据仍会对照分享方给出的指纹校验，所以协助方无法篡改内容。

在 **设置 → 分享 → 正在协助分发** 可以随时关闭，也能看到状态：进行中、已暂停（例如下载次数用完）、分享方离线，或已结束（分享被撤销、过期，或分享方不再接受协助）。已结束的行可以从列表移除，已导入的档案不受影响。

## 嵌入网页

填写了公开地址并在分享上开启 **允许嵌入** 后，分享结果里会给出两段代码，任选其一贴到网页上：

```html
<iframe src="https://你的地址/embed/s/分享码" width="360" height="420" style="border:0;max-width:100%" loading="lazy" referrerpolicy="no-referrer"></iframe>
```

```html
<script src="https://你的地址/embed/share.js" defer></script>
<lrrg-share code="分享码" src="https://你的地址"></lrrg-share>
```

两者显示同一张卡片：封面、标题、数量，以及按权限出现的「阅读」「下载」「导入」入口。项目超过四个时，封面后面的「+N」可以展开完整列表；鼠标停在封面上会放大显示。宽度从 260 px 起自适应。分享被撤销、过期或下载次数用完时，卡片只显示相应状态和置灰的按钮；带有 IP 限制的分享只显示「受限分享」。这些情况都不泄露内容。

卡片配色默认跟随你实例当前的主题。要换一种，给 iframe 地址加上 `?theme=…`，或给 `<lrrg-share>` 加 `theme="…"` 属性；可选 `g`、`ex`、`modern`、`modern_red`、`modern_clear`、`light`、`dark`，以及跟随访客系统深浅色的 `system`。

也可以只改部分颜色：传一个对象，`base` 是基础预设，其余是要覆盖的颜色（`bg` 底色、`fg` 文字、`muted` 次要文字、`border` 边框、`accent` 按钮与强调色、`tile` 封面占位，以及二维码的 `qrFg` 前景、`qrBg` 背景、`qrFinder` 定位器），每一项都可省略，只接受合法的 CSS 颜色。每个预设主题都自带一套二维码配色；自定义时请保持二维码前景与背景有足够对比度：

```html
<lrrg-share id="card" code="分享码" src="https://你的地址"></lrrg-share>
<script>
  document.getElementById("card").theme = { base: "dark", bg: "#101820", accent: "#f2aa4c" }
</script>
```

同样的对象也可以写成 JSON 放进 `theme` 属性，或 URL 编码后作为 iframe 的 `?theme=`。分享结果窗口里的「嵌入网页」可以直接选方式、配色、语言和尺寸，实时预览并生成代码。卡片文字按访客浏览器的语言显示中文、英文或日文，也可以用 `?lang=zh`（`en`、`ja`）固定。

## 连接

分享在实例之间直接传输，没有公网地址的实例也能互相导入。要获得最快的速度，请把实例的 **UDP 端口**（默认 11204，在 **设置 → 分享 → 连接** 中可改）对外开放。

系统开了代理时不需要额外设置：导入和导出会自动使用代理环境变量（`HTTPS_PROXY`、`ALL_PROXY` 等）或 macOS 的系统代理，TUN 模式的代理本来就透明。代理只承载经中继的连接，实例之间的直连不经过它。

不想依赖公共服务时，可以在 **设置 → 分享 → LANrurugi 节点** 填写你自己或朋友的节点，由它们负责查找和中转。
本实例为别人提供中继时，可以限制每个连接的速度，或只允许列出的实例使用。

## 上传速度

**设置 → 分享 → 上传限制** 可以分别限制「自己的分享」和「协助分发」的上传速度与同时服务的人数，并像 BT 客户端一样设置一套「备用限速」，按时间表（例如每天 1:00–8:00）或手动切换。把备用的自身上传速度设为 0 表示暂停：导入方会保留已收到的部分，等恢复后继续；浏览器阅读不受影响。
