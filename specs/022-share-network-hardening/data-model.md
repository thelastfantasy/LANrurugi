# Phase 1 — Data Model: Share Network Hardening

## Settings (existing keys, documented defaults)

| Key | Default | Validation | Meaning |
|---|---|---|---|
| `share_bind_interface` | `""` | must exist on the host when non-empty | interface all sharing sockets use |
| `share_udp_port` | `""` | empty, or 1–65535 | empty = a fresh random port per start/rotation |
| `share_port_rotate` | `"480"` | `0`, or clamped into 360–720 (minutes) | `0` disables rotation; otherwise 6–12 h with ±25 % jitter |
| `share_node_relay_port` | `"11205"` | 1–65535 | the local relay's TCP port; fixed because reverse proxies point at it |
| `share_external_addrs` | `""` | `host:port` or `[v6]:port` list | manual forwarding addresses |
| `share_node_relay_allow` | `""` | `lrrg-node:…` or 64-hex endpoint id | who may use the local relay |
| `plugin_bind_interface` | `""` | must exist when non-empty | interface plugin downloads use |

## Transfer state machine

```
queued ──start──▶ active ──network error──▶ waiting_for_network ──backoff──▶ active
                    │                              │
                    ├──refusal────────────────────▶ failed_refused
                    ├──cancel─────────────────────▶ cancelled
                    └──complete───────────────────▶ done
```

`waiting_for_network` has no attempt limit; backoff is 1, 2, 4, … capped at 60 s and reset on success. `failed_refused`
records the refusal reason (permission, not found, engine incompatibility, integrity).

## Endpoint state

```
stopped ──start──▶ bound ──interface/address change──▶ rebuilding ──▶ bound
   ▲                  │
   └──stop────────────┘
```

An endpoint has `endpoint_id`, `node_code`, `bound_addrs` and `relay`. `rebuilding` keeps the node code and replaces
the identity only on an explicit destroy. State that must survive a rebuild: `sessions` (importer sessions, now
replaceable), `ratios`, `helpers`.

## Rotation state

```
idle ──due──▶ deferring(claim active) ──claim released──▶ rotating ──▶ idle
                    └──max wait (30 min)──▶ skipped (logged) ──▶ idle
```

## Relay access entry

```
{ "peer": "lrrg-node:…" | "<64 hex endpoint id>", "granted_at": "…", "node_code_at_grant": "…" }
```

An entry is invalidated when the granting node destroys/rebuilds; the relay refuses peers whose identity is not in the
current set.

## Repack cache entry

| Part | Meaning |
|---|---|
| key | content hash over archive id + member `(path, size, mtime)` + entry names + compression + format version |
| path | `<temp>/repack/<key>.zip`, published by renaming `<key>.zip.tmp` |
| state | `building` (in-flight, singleflight) → `ready` |
| ttl | 24 h; also evicted by total-size LRU |
| accounting | counted against `tempmaxsize`; reclaimed by the temp sweep |

## Claim (existing)

`claim_id`, archive id, peer, created/expiry, `blobs`. Rotation reads it; rebuild preserves the session it implies.
