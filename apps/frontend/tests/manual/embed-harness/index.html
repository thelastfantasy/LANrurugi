自定义颜色（JS 对象）

给元素的 theme 属性赋一个对象，base 是基础预设，其余是要覆盖的颜色：

document.getElementById("custom").theme = {
  base: "dark", bg: "#101820", fg: "#f5f5f5", muted: "#9aa5b1",
  border: "#2b3a4a", accent: "#f2aa4c", tile: "#1c2a38",
}

也可以直接写在 HTML 属性里（JSON），或给 iframe 地址加 URL 编码后的 JSON：

<lrrg-share … theme='{"base":"light","accent":"#e91e63","border":"#f8bbd0"}'></lrrg-share>
<iframe src="…/embed/s/ME8T5-1ECE3?theme=%7B%22accent%22%3A%22%2300897b%22%7D" …></iframe>

尺寸扫描：固定高 420，换宽度

从配置器允许的最小宽度 260 一直到它允许的最大值 1200。卡片本身是流式的；这里看的是每个宽度下它怎么排。设置框里能保存的范围是 260–1200。

尺寸扫描：固定宽 360，换高度

高度方向设置框允许 200–1200。

极值

配置器两端：260 × 200 与 1200 × 1200。超过 1200 的尺寸设置框不接受，但手写一个更大的 iframe 在页面上仍然能渲染——卡片没有硬上限，只是不提供。

Web Component 自己的尺寸

<lrrg-share> 不用写尺寸：它把宽度交给容器（min-width: 260px、max-width: 480px），高度由卡片通过 postMessage 报告后在 120–1200 之间自动设置。下面分别放在 260、360、480、800 宽的容器里。

跟随容器（100% × 100%）

宽高都写 100% 时 iframe 撑满外层容器，但容器必须有确定高度；容器高度是 auto 时 iframe 会掉回默认的 150px（下面第三个）。卡片页背景是透明的，所以多出来的地方显示的是这一页的背景色。

嵌入代码

<iframe src="http://192.168.3.105:3000/embed/s/ME8T5-1ECE3" width="360" height="420" style="border:0;max-width:100%" loading="lazy" referrerpolicy="no-referrer"></iframe>
<script src="http://192.168.3.105:3000/embed/share.js" defer></script>
<lrrg-share code="ME8T5-1ECE3" src="http://192.168.3.105:3000"></lrrg-share>

指定主题：

<iframe src="http://192.168.3.105:3000/embed/s/ME8T5-1ECE3?theme=ex" …></iframe>
<lrrg-share code="ME8T5-1ECE3" src="http://192.168.3.105:3000" theme="ex"></lrrg-share>

可选值：g、ex、modern、modern_red、modern_clear、light、dark、system。
